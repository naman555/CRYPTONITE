# Variables, expression and statements
> In this module, we learn how to use expression and statements and store the output of these in variables.

## Code:
```python
name = input("Enter your name")
print("Hello", name)
```

```python
hrs = int(input("Enter Hours:"))
rph = float(input("Enter rate per hour"))
print("Pay:", hrs*rph)
```
